# Skill Duel - Design Requirements

**App Name:** Skill Duel
**Platform:** Mobile app (iOS + Android), Flutter
**Theme:** Dark mode only

## Visual Identity
- **Primary Background:** #1A1A2E (Deep navy)
- **Surface/Card Color:** #16213E
- **Accent Color:** #E94560 (Vibrant red-pink)
- **Secondary Accent:** #4A4E8C (Muted indigo)
- **Text Primary:** #FFFFFF
- **Text Secondary:** #A0A0B0
- **Success:** #22C55E
- **Warning:** #F59E0B

## UI Components
- **Font:** Bold, modern sans-serif (Inter or Poppins)
- **Border Radius:** 
    - Cards: 16px
    - Buttons: 12px
    - Avatars: 50%
- **Icon Style:** Minimal, outlined with filled active states
- **Overall Vibe:** Competitive, high-energy, dark gaming aesthetic (inspired by Chess.com and COD UI)
